## 1. 产品定位与铁律

**产品名**：AMAS Christian Profile（基督徒成长与事奉画像）。App 内入口叫「定制化神学」。

**铁律（来自《AMAS Christian Profile Assessment System v1.0》规范）**

1. 四层分别测量、分别呈现，**永远不合成一个总分**：A 信仰基础 / B 门徒生命 / C 事奉倾向 / D 事奉准备度。
2. 信仰知识、灵修实践、事奉经验 **永远不进入** 12 项事奉倾向的计算；倾向只由 C 类（Likert/频率）+ D 类（情境）题目决定。
3. 12 个“角色”不是 12 种互斥类型，而是 **12 项独立的事奉倾向维度**：每个人都有全部 12 项，只是强弱组合不同。结果永远呈现 Top 3 + 全 12 维，不说“你就是 X”。
4. 评分是**确定性引擎**（同样答案永远同样结果）；AI 只能做解释与推荐，不能打分、不能改分。
5. 网页版 10 题只做「信仰成长快速探索」（Level 0），只输出 5 项初步状态，**不判定任何倾向**。
6. 措辞：只用“评估 / 探索 / 画像 / 呈现倾向 / 建议尝试”，不用“诊断”“你就是”“你不适合”“神告诉我们”。
7. 每项倾向必须平衡解读：潜在优势 + 典型贡献 + 可能的盲点 + 成长方向；不用红绿表示好坏。
8. 进度按阶段显示（Step n of 6），不显示 38/84，不显示时长估计；每题自动保存、可退出续答、可撤销上一题。
9. 未经样本验证前标注 Development Edition，不得宣称“科学验证 / 标准化 / 准确率”。

## 2. 三个层级的测评

| 层级 | 名称（用户可见） | 题数 | 内容 | 输出 |
|---|---|---|---|---|
| Level 0 | 信仰成长快速探索（网页版 discover.html） | 10 | 圣经熟悉度 2 / 基础教义 2 / 灵修实践 2 / 事奉参与 2 / 门训意识 2 | 5 项初步状态（稳定/较稳定/发展中/需要建立）+ 一条下一步建议；不输出倾向 |
| Level 1 | 事奉倾向画像 · 精简版（App） | 30 | C 类 24（每维 2 题）+ D 类情境 6 | 12 项倾向指数、Top 3、组合标签、平衡解读、建议侍奉/课程/计划；标注“精简版” |
| Level 2 | Christian Profile · 完整版（App） | 84 | A 12 / B 12 / C 36 / D 12 / E 12，分 6 个阶段 | 以上 + 信仰基础、门徒生命、事奉准备度、倾向×准备度矩阵解读 |

**完整版 6 个阶段**（阶段标题与引导语原文）：

1. **认识你的信仰基础**（12 题）— 这一部分了解你对圣经与基要真理的认识。不必紧张，不确定可以如实选择——这只用于建议装备重点，不会进入事奉倾向的计算。
2. **了解你的生命节奏**（12 题）— 请按过去一个月的真实情况选择。这里记录的是当前的实践状态，而不是对属灵价值的评价。
3. **发现你事奉人的方式**（18 题）— 下面是关于你在教会与生活中自然反应的描述。请按“过去一段时间你实际上怎样”作答，而不是“应该怎样”。
4. **看看你如何面对需要**（12 题）— 每个情境的四个选项都是合理、可接受的做法，没有对错。请选择你最自然会先做的那一个。
5. **探索团队中的你**（18 题）— 继续按真实情况作答。这些描述涉及团队、系统与实际事务中的你。
6. **了解你的实际事奉阶段**（12 题）— 最后几题是关于实际经验的事实，用来区分“倾向”与“准备度”。如实作答即可。

精简版 2 个阶段：**发现你事奉人的方式**（24 题）、**看看你如何面对需要**（6 题）

**答题体验规则**：一题一页；顶部显示“Step n of 6 · 阶段标题”与阶段进度条；每题下方「上一题」可撤销；左上角 ✕ 退出并保存会话，下次进入可「继续上次未完成的评估」或「重新开始」；作答前有知情说明页（这是什么 / 为什么测 / 结果如何使用 / 不是用来做什么）。

## 4. 评分规则（deterministic · provisional_v1）

### 4.1 通用
- 量表值 v∈1–5 → 内部指数 (v−1)/4×100；反向题先做 v→6−v。
- 0–100 是**内部指数**，不是百分位；84 分不等于超过 84% 的人。
- 缺答的题目不计入均值；不会产生 NaN。

### 4.2 C+D → 12 项事奉倾向（唯一进入倾向评分的模块）
- 每一维：Likert 指数 = 该维 3 题（精简版 2 题）指数的平均。
- 情境指数 = 该维在情境题里“被选中次数 ÷ 被提供次数” × 100。
- 维度指数 = 0.8 × Likert 指数 + 0.2 × 情境指数（该维未在情境中出现时 = Likert 指数）。
- 各维独立计分，**不归一化为总和 100%**。
- **倾向指数与证据可信度是两个独立维度**（V2）：指数回答「这个方向表现得有多明显」，
  可信度回答「系统凭什么这样判断」。两者不可互相换算，也不可合并成一个数字展示。
- 证据可信度四档：较低 / 中等 / 较高 / 高。只有测评 + 情境题时**最高只能到中等**，无论指数多高；
  出现任一外部证据（课程完成 / 实际服侍）→ 较高；出现他人观察（导师 / 同伴反馈）→ 高。
- 整份画像的可信度 = Top 3 的**中位数**（取最低值会被第三位单方面拖垮）；任一 Top 倾向被反证时再降一档；
  作答质量标记 ≥2 时每维与整体各降一档。

### 4.10 证据模型（Evidence Model V2.1）——系统凭什么这样判断，以及何时修正自己

每一条证据必须回答三个问题，否则不进入计算：

| 字段 | 含义 | 约束 |
|---|---|---|
| `targetOrientations` | 这条证据在验证**哪几项**事奉倾向 | **不允许为空**。无目标的证据一律丢弃，杜绝「全局证据池」——完成一门无关课程不会抬高任何倾向的可信度 |
| `polarity` | 支持 support / 中性 neutral / **反证 challenge** | 反证是 V2.1 新增，使系统具备修正自己的能力 |
| `strength` | weak / moderate / strong | 决定支持与反证相抵时谁占上风（权重 1 / 2 / 3） |
| `source` | self / peer / mentor / system | 只有 peer 与 mentor 属于「他人的观察」，才能把可信度推到「高」 |
| `observedAt` / `createdAt` | 事情发生时间 / 记录时间 | 两者分开，便于日后按真实时间线重排 |

**反证如何修正判断**（这是 V2.1 的核心）：

- 反证权重 ≥ 支持权重 → `contradicted`：该维可信度**直接压到「较低」**，结果页顶部显示「这份画像需要重新验证」，并说明系统不会因为分数高就坚持原判断；
- 存在反证但支持更多 → `mixed`：可信度降一档，不允许停留在「高」。
- 无论哪种情况，**倾向指数都不变**。被修正的是「系统有多确信」，不是分数本身。

**证据日志**：只追加，不覆盖、不删除。重新评估只清当前画像，历史快照与证据日志一律保留——
这样后来发生的事才能回过头检验当初的测评结论。

**「我愿意尝试」**写入一条 `verification_intent` 证据（neutral / weak）：只表示打算去验证，**不构成支持证据**，因此不提升任何可信度；
真正的证据要等实际服侍或反馈回来才产生。意向跨评估保留。

**判断依据面板的四态**：支持 / 中性 / 反证 / 暂无（V2 只有 强·有·无，无法表达反证）。红色只表示「与当前判断冲突」，不表示属灵上的好坏。

**画像版本号**：按 `completedAt` 幂等——同一次评估重复保存不会虚增 V 号，也不会重复写入历史。

### 4.11 验证闭环（Validation Loop，P2-A）

**先修正一个概念错误**：「我愿意尝试」曾被写成 `verification_intent` 证据。
虽然用 neutral/weak 保证了它不影响可信度，但概念上仍然错位——Evidence 描述**已经发生并被观察到的事实**，
而「打算去做」属于 Intent / Task / Workflow State。从 P2-A 起它进入独立的 `ValidationExperiment` 实体，
**不再写入 Evidence**；旧的 verification_intent 记录仍可读取（自动显示为「待开始」的实验），只是不再新增。

**闭环**：登记实验 → 实践 → 自我复盘 → 导师／同工观察（可选）→ 生成证据 → 回到画像复核。

| 阶段 | 状态 | 允许迁移到 |
|---|---|---|
| 登记 | `not_started` | active / cancelled |
| 实践中 | `active` | completed / cancelled |
| 待复盘 | `completed` | reviewed（**必须先有复盘**）/ active / cancelled |
| 已复核 | `reviewed` | 终态，不可回退（历史只追加） |
| 已取消 | `cancelled` | 终态，不产出证据 |

**复盘结论 → 证据极性**（P2-A.1 修正后）：

P2-A 曾把「未能验证」直接当成反证，这是一个语义错误。「未能验证」实际混着四种完全不同的情况：
做了而且明显不合 / 只有一次机会或场合不对 / 第一次做得吃力（学习曲线）/ 根本没做成。
把它们一律压成 challenge，等于用「新手第一次讲道紧张」去推翻一个人的教导倾向——
方向相反，但性质等同于禁止项里的「用高倾向分数自动推断人格缺点」。因此结论拆成四档：

| 复盘结论 | 极性 | 强度 | 效果 |
|---|---|---|---|
| 验证成立 | support | 完成 ≥2 项行动为 strong，否则 moderate | 可信度升到「较高」 |
| 部分成立 | support | moderate | 计为支持；第一次尝试通常如此 |
| **这次没能判断** | **neutral** | weak | **只记录尝试过，不下调任何判断** |
| **明显不合适** | **challenge** | moderate（自我报告封顶） | 进入冲突逻辑，见下 |

选「这次没能判断」时必须给出原因（机会太少 / 场合不对应 / 刚开始看不出来 / 中途有状况 / 其他），
迫使系统把「没机会验证」与「验证了但不成立」分开记录。

**一次自我报告永远不足以推翻结论**：单条自我报告的反证只判定为 `mixed`（降一档），
文案明说「单独一次还不足以改变判断，值得再验证一两次」。
只有反证**重复出现（≥2 条）**，或**来自导师／同伴的观察**时，才升级为 `contradicted`（压到「较低」）。

措辞铁律：两者都不是「失败」。「明显不合适」说的是这个场合、这个阶段，不是这个人。
旧数据里的 `not_confirmed` 语义含混，一律保守读作「这次没能判断」，**绝不追认为反证**。

**导师观察的诚实性约束**：由用户本人转述的反馈记为 `verified: false`，生成证据时 `source` 记为 `self`，
因此**不算他人观察**，可信度上限停在「较高」，不能到「高」。只有通过导师端确认的观察才是真正的他人证据。
（完整牧者后台不在本轮范围，此约束保证在后台就绪前不会出现虚高的可信度。）

**不变量**：实验产出的证据仍然只影响证据可信度，**不改动任何倾向指数**。
- 可解释性：用户在该维答“比较符合/经常”以上的题目，其解释标签被记录为“为什么这一维较高”的来源；不展示权重。

### 4.3 A → 信仰基础
- 4 个面向（圣经理解 / 福音理解 / 基础教义 / 教会与门徒生活）各 3 题，按正确率计 0–100；整体 = 四面向平均。仅用于装备建议。

### 4.4 B → 门徒生命
- 8 项实践（读经、祷告、敬拜、团契、顺服实践、服事、奉献、见证）按频率指数平均；状态等级：≥75 稳定 / ≥55 较稳定 / ≥35 发展中 / 其余 需要建立。措辞是“当前实践状态”，不是属灵价值评价。

### 4.5 E → 事奉准备度
- 8 个面向（实际经验、持续性、责任承担、接受装备、导师反馈、团队配搭、带领经验、实践证据）各 1–2 题；整体 = 面向平均；等级：≥70 较充分 / ≥45 发展中 / 其余 起步阶段。

### 4.6 Top 3 与组合标签
- 12 维按指数降序，取 Primary / Secondary / Supporting。
- 若第 1 与第 3 名相差 ≤3 分 → 标记「多元事奉组合」，不强行命名单一主倾向。
- 组合标签 = 次要倾向的修饰形 + 主要倾向名（如「装备型教导者」「劝勉型牧养者」）。**组合标签只是解释用语，不是新类型。**

### 4.7 倾向 × 准备度矩阵（完整版）
| 主倾向指数 | 准备度 | 解读 |
|---|---|---|
| ≥70 | <50 | 倾向明显但训练与实践证据仍在建立——建议进入装备阶段，而不是立即承担更大责任 |

| 其他 | 其他 | 方向形成中——在实践与群体反馈中继续观察 |

### 4.8 作答质量标记（只降低解释强度，绝不屏蔽用户）
- `too_fast`：≥10 题时中位作答时间 <1.2 秒；`straight_lining`：≥12 道量表题中 ≥90% 选同一选项；`high_inconsistency`：≥3 个维度的反向题与正向题差距 >50；`missing_items`：有题未答。
- 整体证据强度：≥2 个标记 → 有限；精简版或 1 个标记 → 中等；完整版且无标记 → 充分。结果页用一句话说明“本次作答……因此更适合作为探索参考”。

### 4.9 推荐引擎（规则式）
- 推荐验证场景 = 主倾向常见侍奉前 4 + 次要倾向前 2（去重）。措辞固定为“建议尝试 / 验证场景”，不得表述为职位安排。
- 装备重点先于课程：先说明「为什么建议这些内容」，再分三档给课（优先学习 / 推荐学习 / 后续可学习），避免一次给太多。
- 若信仰基础整体 <60，前置「认识圣经」「基督徒生活基础」并把“信仰基础与圣经整体脉络”列为装备重点。
- 完成课程只增加学习证据（提升可信度），**不会提高任何倾向指数**；指数只有重新评估才更新。
- 若准备度整体 <50，前置“寻找一位导师或牧者，约定每月一次服事反馈”；导师反馈面向 <40 再加“邀请牧者观察一次服事并反馈”。
- 成长计划为**成长实验**结构，每阶段含四段：成长目标 / 行动 / 验证指标 / 新增证据。
  30 天验证能力是否成立、90 天进入真实服侍接受检验、6 个月重新生成画像并对比两版差异。

## 8. 固定文案

**知情说明（评估前）**：这是什么 / 为什么测 / 结果如何使用 / 不是用来做什么（不衡量属灵价值，不判定教会职分或呼召，不替代圣经、祷告、教会群体与牧者的长期辨识）。

**评估声明（答题页常驻）**：本评估依据 AMAS 神学与门训框架设计，帮助你认识当前的信仰基础、成长状态与装备需要。结果用于成长与装备参考，不作为个人价值、属灵程度或教会任职资格的判断。

**结果页免责声明**：AMAS Christian Profile 旨在帮助基督徒认识自己的信仰基础、成长实践、事奉倾向和装备需要。评估结果属于发展性参考，不用于衡量个人属灵价值，也不替代圣经、祷告、教会群体、牧者或导师的长期辨识。事奉方向应在真实生命、群体关系与持续实践中进一步确认。

**倾向声明**：事奉倾向用于帮助理解当前呈现的恩赐、能力、侍奉与成长倾向，不等同于属灵身份、教会职分或神对个人呼召的最终确认。方向的确认应继续结合圣经、祷告、教会群体、导师、真实侍奉与长期果效进行辨识。

**Level 0 免责声明**：这是基于少量问题形成的初步探索结果，不代表完整 Christian Profile。完成标准评估后，系统将使用更多行为、情境和实践信息生成更稳定的成长档案。
