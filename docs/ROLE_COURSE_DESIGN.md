# AMAS 定制化课程体系 · 设计构思档案

> 12 项事奉倾向 → 专属课程包
> 版本：草案 v0.1（供确认，尚未实现）　日期：2026-08-28
> 依据：《AMAS Christian Profile Assessment System v1.0》· 官方课程目录 67 门（`services/catalog.ts`）

---

## 0. 这份文档要解决什么

结果页现在只到「你最明显的三项事奉倾向」为止，用户看完知道自己是谁，却不知道**下一步该学什么**。本文档设计 Top 3 倾向 → 定制课程的完整规则，并盘点为此需要新增哪些课程。

三条硬约束（承接评估规范）：

1. **推荐依据倾向组合，不依据单一角色**。同样是「劝勉者」，配「差传者」和配「建造者」，推荐必须不同。
2. **推荐是“建议尝试”，不是“你必须学”**。措辞、排序都不能暗示强制或等级。
3. **倾向决定方向，准备度与信仰基础决定起点**。三层数据各司其职，不混算。

## 1. 覆盖度体检：现有 67 门够不够？

| 倾向 | 现有可直接用的课程 | 覆盖判定 |
|---|---|---|
| 01 教导者 | 研经标记法、平信徒系统神学、讲道学、讲道实习、主日学教育、基督教教育 | **良好**，缺正式释经学 |
| 02 研道者 | 研经标记法、希腊语、希伯来语、圣经地理、世界教会史、改革宗与福音派神学 | **中**，缺释经学原理、旧约概论、研究方法 |
| 03 装备者 | 门徒训练、新信徒事工/教材、小组运营、主日学教育、基督教教育 | **中**，缺「培训培训者」层 |
| 04 牧养者 | 协谈学、门徒训练、小组运营、内在医治 | **中**，缺牧养学正课、界限 |
| 05 劝勉者 | 协谈学、确信生活、门徒训练 | **弱**，缺圣经辅导、青少年与家庭 |
| 06 怜悯者 | 内在医治、神的话语医治、基督徒生活基础 | **弱**，缺慈惠事工、危机关怀、界限 |
| 07 代祷者 | 祷告与灵修生活、属灵争战、敬拜学 | **中**，缺祷告神学、诗篇与属灵操练 |
| 08 传福音者 | 传道法、罗马书、新信徒事工、中国异端、宗教比较 | **中**，缺护教学、个人布道实操、跟进系统 |
| 09 差传者 | 处境化神学、伊斯兰教理解、宗教比较、以色列文化 | **弱**，缺宣教学概论、跨文化沟通、植堂 |
| 10 领袖者 | 教会运营、小组运营、平信徒系统神学 | **弱**，缺仆人领导、团队与冲突、教会治理 |
| 11 建造者 | 教会运营、人工智能与教牧实践、礼拜学 | **弱**，缺事工管理、管家神学、媒体技术 |

**结论**：现有目录严重偏向「圣经书卷 + 教导/牧养」，对 CARE 后段、MISSION、BUILD 三个群组（怜悯、代祷、差传、领袖、建造、服事）供给不足。12 项倾向里有 6 项拿不出一门真正对口的核心课——这正是必须补课的地方。

## 2. 课程包模型（每个倾向五层）

```
L0 共同根基   所有人共享，按信仰基础分数决定是否前置
L1 核心必修   这一倾向的定义性能力（2 门）
L2 支撑选修   拓宽与深化（2–3 门）
L3 盲点补强   针对该倾向文档化的盲点（1 门）★ 本设计的关键
L4 实践任务   非课程，进入服事记录与证据层
```

**L3 盲点补强是这套设计的核心差异点。** 评估规范要求每项倾向必须平衡解读（优势 / 贡献 / 盲点 / 成长方向），课程推荐若只给优势课，等于只夸不帮。所以每个包必须带一门直接对应盲点的课程：

| 倾向 | 文档化盲点 | 盲点补强课 |
|---|---|---|
| 教导者 | 知识可能大于生命 | 门徒训练（生命操练） |
| 研道者 | 停留研究、实践不足 | 讲道实习 / 小组运营 |
| 装备者 | 把人当项目、忽略陪伴 | 牧养学 |
| 牧养者 | 难以设立界限、情绪耗竭 | **界限与自我照顾** |
| 劝勉者 | 太快给建议、倾听不够 | **圣经辅导（倾听技巧）** |
| 怜悯者 | 情绪卷入、难以拒绝 | **界限与自我照顾** |
| 代祷者 | 主观感觉替代分辨、缺行动 | 基督教伦理 / 属灵操练 |
| 传福音者 | 追决志数字、跟进不足 | **初信跟进系统** |
| 差传者 | 过快行动、文化理解不足 | **跨文化沟通** |
| 领袖者 | 控制、忽略弱者 | **仆人领导** |
| 建造者 | 系统大于人、沟通偏少 | **团队建设与冲突管理** |
| 服事者 | 不会拒绝、长期被忽视 | **界限与自我照顾** |

（加粗为待新增课程）

## 3. 推荐算法规范

### 3.1 组合取课
```
主倾向（Primary）    → L1 全部（2 门）+ L3 盲点补强（1 门）
次倾向（Secondary）  → L1 取 1 门（与主倾向去重后的第一门）
第三倾向（Supporting）→ L2 取 1 门
并列（topTie=true）  → 主次各取 L1 2 门，盲点补强取双方共同项或主倾向项
```

### 3.2 起点调节（不改变方向，只改变顺序）
```
信仰基础 < 60 或未评估  → 队首插入 L0：认识圣经、基督徒生活基础（最多 2 门）
准备度 < 50            → 在实践任务中前置「寻找导师，每月一次反馈」
导师反馈面向 < 40      → 追加「邀请牧者观察一次服事并反馈」
精简版画像（quick）     → 课程数上限 5，并提示完整版会给出更精准的路径
```

### 3.3 输出规则
- 去重后**总数 5–8 门**，按 L0 → L1 → L3 → L2 排序（先根基，再核心，再补盲点，最后拓展）
- 每门课标注**推荐理由**（来自哪一项倾向 / 是否为盲点补强），可解释、可追溯
- 讲义筹备中的课程照常展示，标注「筹备中」，不占用“可立即开始”的名额
- 每门课带一个**完成后的实践动作**，接入服事记录（Evidence 层）

### 3.4 分阶段呈现
```
第一阶段（30 天）  L0 或主倾向 L1 第一门 + 1 个实践动作
第二阶段（90 天）  主倾向 L1 第二门 + L3 盲点补强
第三阶段（6 个月） 次/第三倾向课程 + 复评 Christian Profile
```

## 4. 12 个倾向的课程包明细

> 标注：**[新]** = 需新增课程；其余为现有 67 门中的课程

### 01 教导者 Teacher
- **L1 核心**：**[新] 释经学原理**、讲道学
- **L2 支撑**：平信徒系统神学、主日学教育、**[新] 圣经神学：救恩主线**
- **L3 盲点**：门徒训练（把所教的活出来、带一个人）
- **L4 实践**：预备并讲一次 15 分钟信息，请一位同工反馈

### 02 研道者 Scripture Explorer
- **L1 核心**：**[新] 释经学原理**、**[新] 旧约概论**
- **L2 支撑**：希腊语、研经标记法、世界教会史
- **L3 盲点**：讲道实习（把研究讲给普通信徒听）
- **L4 实践**：完成一卷书信的背景研究，整理成一页讲义

### 03 装备者 Equipper
- **L1 核心**：门徒训练、**[新] 门徒训练师资培训**
- **L2 支撑**：主日学教育、基督教教育、小组运营
- **L3 盲点**：**[新] 牧养学**（陪伴过程，不只是训练进度）
- **L4 实践**：带一位初信者完成 4 周门训，记录每次的进展

### 04 牧养者 Shepherd
- **L1 核心**：**[新] 牧养学**、协谈学
- **L2 支撑**：门徒训练、小组运营、**[新] 青少年与家庭事工**
- **L3 盲点**：**[新] 界限与自我照顾**
- **L4 实践**：固定跟进 1–2 位肢体，每两周一次，持续 8 周

### 05 劝勉者 Encourager
- **L1 核心**：**[新] 圣经辅导**、协谈学
- **L2 支撑**：确信生活、门徒训练、**[新] 青少年与家庭事工**
- **L3 盲点**：**[新] 圣经辅导**中的倾听单元（先听后劝）
- **L4 实践**：每周主动鼓励一位灰心的人，记录三次后对方的实际改变

### 06 怜悯者 Mercy Giver
- **L1 核心**：**[新] 慈惠与社区关怀事工**、内在医治
- **L2 支撑**：神的话语医治、**[新] 危机与创伤关怀**、基督教伦理
- **L3 盲点**：**[新] 界限与自我照顾**
- **L4 实践**：参与一次探访，为一位有需要的人提供具体帮助并设定界限

### 07 代祷者 Intercessor
- **L1 核心**：**[新] 祷告神学与守望事工**、祷告与灵修生活
- **L2 支撑**：属灵争战、敬拜学、诗篇（含于祷告神学）
- **L3 盲点**：基督教伦理（分辨与行动，不以感觉替代印证）
- **L4 实践**：建立代祷名单并持续 30 天，记录应允与调整

### 08 传福音者 Evangelist
- **L1 核心**：**[新] 个人布道与福音对话**、传道法
- **L2 支撑**：罗马书、**[新] 护教学**、宗教比较
- **L3 盲点**：**[新] 初信跟进系统**
- **L4 实践**：列出 3 位未信朋友，完成一次自然的福音性交谈并跟进

### 09 差传者 Missionary
- **L1 核心**：**[新] 宣教学概论**、处境化神学
- **L2 支撑**：**[新] 未得之民与宣教策略**、伊斯兰教理解、以色列文化
- **L3 盲点**：**[新] 跨文化沟通**
- **L4 实践**：认领一个未得之民群体，持续祷告并完成一份了解报告

### 10 领袖者 Leader
- **L1 核心**：**[新] 仆人领导**、教会运营
- **L2 支撑**：小组运营、**[新] 教会治理与长执同工**、**[新] 植堂学**
- **L3 盲点**：**[新] 团队建设与冲突管理**
- **L4 实践**：带领一次活动的筹备与执行，与导师复盘

### 11 建造者 Builder
- **L1 核心**：**[新] 事工管理与项目管理**、教会运营
- **L2 支撑**：**[新] 管家神学与教会财务**、**[新] 教会媒体与技术事工**、人工智能与教牧实践
- **L3 盲点**：**[新] 团队建设与冲突管理**（系统为人服务）
- **L4 实践**：为一项事工设计一份可复用的流程或表格并试运行

### 12 服事者 Servant
- **L1 核心**：**[新] 接待与后勤事工**、**[新] 恩赐辨识与团队配搭**
- **L2 支撑**：礼拜学、教会运营、**[新] 义工管理与配搭**
- **L3 盲点**：**[新] 界限与自我照顾**
- **L4 实践**：承担一个固定后勤岗位 4 周，并邀请同工给一次反馈

```

─────────────────────────────

   ▸ 圣经辅导        来自「劝勉者」· 核心      [筹备中]

   ▸ 个人布道与福音对话  来自「传福音者」
   ▸ 重做 Christian Profile，对比倾向与准备度的变化
─────────────────────────────
 路径依据你的 Top 3 倾向生成，属于建议尝试；
```

要点：
- 每门课都显示**推荐理由**（来自哪一项倾向 / 盲点补强），不做黑箱推荐

- 阶段之间用竖线连接，视觉上是一条路径而不是一堆标签
- 底部固定一句“建议尝试 + 与牧者讨论”的措辞
