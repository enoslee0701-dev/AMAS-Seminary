## 0. 前置配置

```
# backend（secret 只放服务端，绝不进 VITE_*）
LIVEKIT_URL=wss://<your>.livekit.cloud
LIVEKIT_API_KEY=<key>
LIVEKIT_API_SECRET=<secret>

# 前端 .env.local
VITE_VOICE_TRANSPORT=livekit
```

启动后端，确认日志出现：

```
[amas-backend] VOICE SERVICE READY — livekit url=wss://...
```

若出现 `VOICE SERVICE NOT READY`，先修配置再开始。

诊断面板：在祷告室 URL 后加 `?voiceDebug=1`
（生产环境还需额外配置 `VITE_ALLOW_VOICE_DEBUG=1`，默认关闭）。
